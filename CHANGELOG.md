# Changelog

## Unreleased

## 0.2.0

- Search as you type and open titles on animepahe from search results or the anime page.
- Select episode ranges with Shift-click. The episode picker now uses clicks, Shift-click, All, and None in place of the typed range field.
- Simplify setup and download instructions and move local development details into the contributor guide.

## 0.1.1

- Use literal environment defaults and explicit volume fields in the release
  Compose file so graphical importers do not misparse variable expressions.

## 0.1.0

- Portable `.env` configuration and a local Docker stack with FlareSolverr.
- Configurable server storage paths and settings.
- Search/test loading descriptions and a persistent light/dark mode switch.
- Version metadata in the CLI, UI, and container labels.
- PR validation, tag-only multi-platform image releases, and portable Compose installer.
